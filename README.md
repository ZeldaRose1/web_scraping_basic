# web_scraping_basic
Simple web scraping with Python and requests package. Intended to pull data from FF XIV Lodestone website for further analysis.

The code works and it will pull data, but it was far too slow to be practical. This could work for smaller websites where you needed to scrape public data, but for anything as large as an MMO database it would be best to run it through an official API. It was a fun project to get a little more familiar with HTML and web scraping though.
